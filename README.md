# Задание 3: Автотесты для UI

UI-автотесты для проверки сервиса Stellar Burgers.

## Реализованные сценарии

### Конструктор
Созданы тесты для проверки:
- перехода в раздел «Конструктор»;
- перехода в раздел «Лента заказов»;
- открытия всплывающего окна с деталями ингредиента;
- закрытия всплывающего окна с деталями ингредиента;
- увеличения счётчика ингредиента после добавления ингредиента в заказ.

### Лента заказов
Созданы тесты для проверки:
- увеличения счётчика «Выполнено за всё время» после создания заказа;
- увеличения счётчика «Выполнено за сегодня» после создания заказа;
- появления номера заказа в ленте заказов.

## Структура проекта

- `tests` — пакет с UI-тестами, разделёнными по функциональности;
- `pages` — пакет с Page Object для страниц и общих элементов;
- `helpers` — вспомогательные методы для работы с API и ожиданиями;
- `locators.py` — локаторы элементов страниц;
- `data.py` — тестовые данные и базовые URL;
- `allure-results` — результаты выполнения тестов для генерации Allure-отчёта.

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск автотестов

```bash
pytest
```

Запуск в headless-режиме:

```bash
pytest --headless
```

Запуск в конкретном браузере:

```bash
pytest --browser chrome
pytest --browser firefox
```

## Генерация Allure-отчёта

```bash
pytest
allure generate allure-results -o allure-report --clean
allure open allure-report
```
